What the check actually does

The guest invokes the existing lab-tool acceptance against its own Axum HTTP server: denied read → owner grants access → permitted read → owner revokes access → denied read. The expected real response sequence is 403 → 204 → 200 → 204 → 403.

A completed download or boot is not a passing authorization test. This page reports success only after the native acceptance program completes successfully inside the guest.

This is a minimal in-browser acceptance console, not the full interactive catalog UI or a production deployment. The complete UI remains available in the private Codespaces/local Docker lab linked from the main page.
