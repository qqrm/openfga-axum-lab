Roles and inheritance
A user's role assignment can grant a privilege on a project. Effective privileges flow through warehouse and namespace parents to a table. Operations ask the model's can_* relations.

  select → project:acme

project:acme
  warehouse → warehouse:analytics

namespace:metrics
  parent → warehouse:analytics

lakekeeper_table:analytics/requests
  parent → namespace:metrics

Scope and attribution
The full model is preserved byte for byte. The lab implements a documented subset of catalog operations; it is a separate application, not the Lakekeeper server. Accounts, projects and table metadata are synthetic. Provenance includes the upstream commit, original path, license and SHA-256.
